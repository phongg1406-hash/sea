# Design Specification Sources

## Approved Design Direction

The Sunlit Shore project follows an approved design direction characterized by:

- Tropical beach-inspired interactive portfolio.
- Playful Brutalism, with a bright and stylized visual language.
- One-page structure combined with Bento Grid and Project Gallery.
- A website-wide spatial canvas.
- Hybrid postcard and minimal project cards.
- Stylized Directional Water Wake responding to cursor movement.
- Performance-first, accessibility-first development.
- Code-first visuals, without requiring AI image generation or Vision capabilities.
